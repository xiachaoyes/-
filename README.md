# 零代码AI建站 — 用户代码托管仓库

基于 GitHub 的**自动代码备份与版本管理仓库**，用于存储零代码 AI 建站平台中每位用户通过 QQ 机器人创建和部署的网站源代码。

---

## 仓库地址

```
https://github.com/xiachaoyes/-
```

---

## 仓库用途

当 QQ 用户在机器人对话中**部署网站**时，系统会：

1. 调用零代码生成平台后端，将代码打包下载
2. 自动解压并按用户/应用归类上传至本仓库
3. 每次部署 = 一次 Git Commit，保留完整历史

---

## 提交历史

每次部署自动生成一条 Git Commit，格式为：

```
deploy: 公司官网(100) by user 123456789
```

可以通过 GitHub 网页查看每次部署的代码变化。

---

## 工作原理

```
QQ用户说"部署" 
  → QQ适配器调用平台部署接口（获取公开访问URL）
  → 下载代码ZIP（过滤 node_modules、.git、dist 等）
  → 解压到临时目录
  → 通过 GitHub API 上传到对应用户分支的对应目录
  → 清理临时文件
  → 返回部署URL + GitHub同步状态给QQ用户
```

---

## 代码上传者

所有提交由自动化机器人完成：

- **提交者**：QQ Adapter Bot
- **邮箱**：bot@qq-adapter.local
- **认证方式**：GitHub Personal Access Token (Classic)

---

## 安全说明

- 使用 GitHub Classic PAT 进行 API 认证，Token 仅存储在服务器配置文件（`application.yml`）中
- Token 权限仅勾选 `repo`（仓库读写），不包含任何其他权限
- 用户代码通过独立分支隔离，互不影响
- 不存储任何敏感信息（`.env` 等文件已在上传前过滤）

## 所属系统

本仓库是以下系统的组成部分：

| 模块 | 说明 |
|------|------|
| 微信小程序 | 用户入口，WebView 加载对话页面 |
| QQ适配器 (qq_adapter) | 基于 NapCat 接收QQ消息，AI Agent 驱动 |
| 零代码生成平台 (yu-ai-code-mother) | AI 对话生成网站代码 |
| 前端 (yu-ai-code-mother-frontend) | 零代码平台 Web 界面 |
| **本仓库 (xiachaoyes/-)** | **用户网站代码的 Git 托管** |
